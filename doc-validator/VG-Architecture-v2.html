Key changes from v1

  1. Removed in-memory state → stateless services + Redis (v1's in-memory contradicted horizontal scaling).
  2. Polling + mutex → managed queue (SQS/Service Bus) with DLQ; SDx events preferred, polling fallback.
  3. Added object storage (S3/Blob) for docs, evidence & reports — missing in v1.
  4. Added Edge/WAF, API Gateway, SSO, Secrets, Observability, CI/CD — the platform a product needs.
  5. Model Gateway in front of the LLM(s), with a data-governance guardrail; consolidate to one approved primary.
  6. “Needs DC Review” outcome + DC Review UI + feedback loop — confidence routing & accuracy tuning.
  7. Config & Rules store — acceptance criteria / thresholds are versioned data, not hard-coded.

Cloud decision & the S3 / EC2 question

  1. Pick ONE cloud + ONE primary model. v1 already spans Google + Azure; adding AWS = 3 clouds, 3 governance reviews, cross-cloud egress.
  2. S3 = yes — object storage is essential (or Azure Blob). Now a first-class box.
  3. Raw EC2 = avoid. Use managed containers (Fargate/Container Apps); EC2 only if self-hosting a model, which isn't needed with managed LLM APIs.
  4. If AWS-primary: use Bedrock + Textract to keep data in AWS — don't call Azure OpenAI/Gemini cross-cloud.
  5. Recommendation: Azure-primary is lower-friction (SDx + Azure OpenAI already there); go AWS only if mandated.
